# Ideas

Some ideas for projects, features, or improvements that could be implemented in the future. This document serves as a brainstorming space for potential enhancements and innovations.

- Create an output expander (Expander1) adding 4 more analog outputs with it's own DAC and OpAmp using the same I2C bus but on a different address. This would allow for a total of 6 analog outputs on the V2 board. Also expose the fourth ADC input on this board.
- Create an input expander (Expander2) allowing the user to have 8 inputs with an I2C ADC (define if that would be 4 potentiometers and 4 CV inputs or 8 CV inputs or a mix of those). This would allow for a total of 8 inputs on the V2 board. This would allow a more hands-on control to the modules.
